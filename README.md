# links.cecillie.fr

Page de liens de [Cécile Ricordeau](https://www.cecillie.fr), illustratrice française (alternative à <https://linktr.ee/cecillie>).

Propulsé par [Links](https://github.com/Cecilapp/Links) ([Cecil](https://cecil.app), Tailwind CSS et Font Awesome).

## Utilisation

```bash
composer install
php cecil.phar serve --open   # prévisualisation
php cecil.phar build          # génération dans _site/
```

- Configuration du site et réseaux sociaux : [`cecil.yml`](cecil.yml)
- Liste des liens : [`pages/index.md`](pages/index.md)
- Avatar : [`assets/avatar.png`](assets/avatar.png)
